🎯 QUICK START (30 seconds)
============================

----------
1. chmod +x setup.sh
2. ./setup.sh
3. Edit trace_analysis.py (line ~30): CONFIG['input_file'] = 'your_data.csv'

🎓 ANALYSIS PIPELINE
====================

The script performs these steps automatically:

1. DATA LOADING
   ├─ Load CSV data
   ├─ Check class balance
   └─ Handle missing values

2. EXPLORATORY ANALYSIS
   ├─ Feature distributions
   ├─ Target distribution
   └─ Initial insights

3. FEATURE ENGINEERING
   ├─ One-hot encode categoricals
   ├─ Remove constant features
   └─ Handle missing values

4. CORRELATION ANALYSIS
   ├─ Feature correlation matrix

5. MODEL TRAINING

6. MODEL EVALUATION

7. FEATURE IMPORTANCE
   ├─ Model-specific importance
   └─ Comparative rankings

8. SHAP ANALYSIS
   ├─ Feature contributions
   ├─ Interaction effects
   └─ Interpretability plots

9. SUMMARY REPORT
   └─ Comprehensive findings

⚙️ CUSTOMIZATION
================

Edit CONFIG dictionary in trace_analysis.py:

Essential Settings:
├─ input_file:        Path to your CSV
├─ output_dir:        Where to save results
├─ target_column:     Column to predict
├─ exclude_columns:   Columns to ignore
└─ categorical_columns: Columns to encode

Model Settings:
├─ test_size:         Train/test split ratio
├─ cv_folds:          Cross-validation folds
├─ random_state:      Random seed
└─ use_xgboost:       Enable/disable XGBoost

Thresholds:
├─ high_correlation_threshold: Flag redundant features
└─ vif_threshold:             Multicollinearity limit

Visualization:
├─ figure_dpi:          Plot resolution
└─ max_features_to_plot: Features in plots

See config_examples.py for more options!

🔬 UNDERSTANDING THE RESULTS
=============================

Best Model Selection:
→ Look at F1 Score (best for imbalanced data)
→ Check ROC-AUC for discrimination ability
→ Review confusion matrix for error types

Feature Importance:
→ Top features from feature_importance_*.csv
→ SHAP plots show how features contribute
→ Correlation with target shows direction

Model Quality:
→ CV F1 close to Test F1 = good generalization
→ Large gap = overfitting
→ Low scores = need better features

🚨 COMMON ISSUES
================

"XGBoost not available"
└─ Install: pip install xgboost
└─ Or set: CONFIG['use_xgboost'] = False

"SHAP not installed"
└─ Install: pip install shap
└─ Analysis continues without SHAP

"Memory error"
└─ Reduce max_features_to_plot
└─ Sample data for SHAP

"Perfect accuracy but makes no sense"
└─ Data leakage! Check exclude_columns
└─ Remove features that contain the answer
