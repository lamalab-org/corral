# Codebook - model identification

Each `dataset_*.csv` is tab-separated and holds an independent anonymised sample answering the same twelve items. Responses run from 1 (low) to 5 (high); `0` denotes a missing response.

| variable | meaning |

| `Q01` | ordered response, 1 to 5 |

`candidate_models.csv` gives each model's description and lavaan-style syntax. The order of the catalogue carries no information.
