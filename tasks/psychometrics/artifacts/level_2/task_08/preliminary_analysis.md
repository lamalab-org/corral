# Preliminary analysis

The two-factor model fits the development sample poorly. Several item-level modification indices are large and the analyst proposes adding whichever paths improve fit, starting with the largest. On that rule the model reaches an excellent development fit.

The proposed changes have not been separated into residual dependence, cross-loading, group-dependent item behaviour or weak item quality, and the replication file has not been opened. Treat the development fit as a set of hypotheses rather than a finished model.
