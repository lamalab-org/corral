# Corral Landing Page

Static landing page for the Corral benchmark. Built with Tailwind CSS + Alpine.js via CDN (no build tools).

## Quick Start

```bash
# 1. Extract environment data from task sources
source .venv/bin/activate && uv run python site/extract_data.py

# 2. Serve locally
cd site && python -m http.server 8080
```

Then open http://localhost:8080.

## Files

| File | Description |
|---|---|
| `index.html` | Main page (Tailwind + Alpine.js) |
| `data.js` | Environment data (generated by `extract_data.py`) |
| `extract_data.py` | Extracts tools, tasks, and scoring functions from task sources using AST |
| `corral_logo.png` | Logo asset |
| `corral_arch.png` | Architecture diagram |

## Regenerating Data

Run from the repo root whenever task sources change:

```bash
source .venv/bin/activate && uv run python site/extract_data.py
```

This parses `tools.py`, `score.py`, and task JSON configs for all environments and outputs `data.js`.
