Reading the comparison
The top panel shows the selected source message. The panels below show the saved annotations for that message.
Direct Decisions classifies whole windows of up to 16 messages, with 4 overlapping. Its pattern statuses are context for this message, not labels attributable to the message alone. Select either window when a message belongs to two.
Graph panels show nodes supported by this message and edges supported here or connected to these nodes. Endpoint buttons jump to the corresponding messages. Unlabelled messages are allowed; they are different from pending, failed, or refused annotations.
Long tool outputs were clipped for annotation. Switch to “Annotation input” to inspect the text the annotators saw. Messages after the final submission remain in the source but were not annotated.
The message map compares node types and counts between the graph methods only. Equal types do not imply equal meaning or evidence. Direct Decisions also receives task context; the graph and direct pattern results have different aggregation semantics.
Message numbers start at 1 in the interface. Saved JSON uses indices starting at 0. The JSON downloads preserve those original indices.
