Reading the annotations
Each annotator automatically shows a saved run matching the selected trace, preferring complete annotations. Run details identify the chosen run.
Each side shows nodes with support in the current message. If a node has no valid support indices, its recorded time is used. Message numbers start at 1; stored indices start at 0.
The message map compares node types and their counts. Matching counts do not imply matching meanings, quotes, or edges. Differences are available when both annotations are complete and the message was not clipped.
Click a supporting quote to highlight it in the original message. Links to other messages and related nodes let you follow the evidence. Run details include saved quality warnings.
