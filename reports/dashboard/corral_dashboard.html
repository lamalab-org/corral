How these numbers are made

Scope
Corral MD, inference optimization, psychometrics, resistor network (Docker sandbox runs), retrosynthesis, spectra elucidation, stargazer and wetlab, from reports/<environment>/trials.csv on the report_audit branch. Every task was tried 5 times.
pass@k and pass^k
As in corral.report.metrics: for a task with pass rate p over its 5 trials, pass@k = 1 − (1 − p)^k and pass^k = p^k. Each is averaged over a level's tasks, then over the environment's levels, then over environments for All.
Cost
Input and output tokens times each model's list price per 1M tokens, from the price list in Sources (Kimi K3 at OpenRouter rates). The cached estimate bills 90% of input at cache-read price. Neither is an invoice.
Errored
Trials whose report records an error, such as a budget limit or an agent crash. They count as failures.
Wall time
Includes queueing and rate-limit waits, so it compares poorly across agents run on different infrastructure.
Audit
Retrosynthesis was rescored on 2026-10-23 after the audit found invalid routes passing. Resistor network host runs that read answer files were replaced by sandboxed reruns.
